## Topics Covered

- SELECT DISTINCT
- COUNT and COUNT DISTINCT
- Filtering with WHERE
- AND / OR
- BETWEEN
- LIKE and NOT LIKE
- Wildcards `%` and `_`
- IN
- NULL values: IS NULL / IS NOT NULL
- Aggregate functions: MIN, MAX, AVG, COUNT
- ROUND
- Arithmetic operations
- Sorting with ORDER BY
- GROUP BY
- Filtering grouped results with HAVING

## Learning Goal

Build a stronger foundation in SQL for data analysis and data engineering by
filtering, aggregating, grouping, and sorting data.

## Key Takeaways

- `WHERE` filters individual rows before aggregation.
- `GROUP BY` groups rows for aggregate calculations.
- `HAVING` filters groups after aggregation.
- Aggregate functions such as `AVG()`, `COUNT()`, `MIN()`, and `MAX()` summarize data.
- `ORDER BY` controls the final sorting of query results.
- `NULL` requires `IS NULL` or `IS NOT NULL`, not `= NULL`.
