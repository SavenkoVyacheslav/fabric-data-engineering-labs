## Topics Covered

- Combining data vertically with UNION ALL
- UNION / UNION DISTINCT
- Combining data horizontally with JOINs
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Joining tables with `ON`
- Joining tables with `USING`
- Multi-column joins
- Composite keys
- Joining multiple tables
- Aggregations after joins
- COUNT and COUNT DISTINCT with joined data

## Learning Goal

Learn how to combine data from multiple relational tables and datasets using
SQL set operations and joins.

## Key Takeaways

- `UNION ALL` appends result sets vertically and keeps duplicates.
- `UNION` combines result sets vertically and removes duplicate rows.
- `INNER JOIN` keeps only rows that match in both tables.
- `LEFT JOIN` keeps all rows from the left table and matching rows from the right table.
- `RIGHT JOIN` keeps all rows from the right table and matching rows from the left table.
- `ON` defines the relationship between tables.
- `USING(column)` can simplify joins when both tables use the same join-column name.
- Multiple columns can be used in a join when a relationship depends on a composite key.
- Multiple JOIN operations can be chained to combine more than two tables.
